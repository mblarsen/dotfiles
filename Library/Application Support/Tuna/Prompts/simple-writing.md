description: Rewrite prose in clear Simplified Technical English.
---
Rewrite the input in clear, direct prose based on ASD-STE100 Simplified Technical English.

Preserve the meaning, facts, technical terms, tone, and language. Do not change code, identifiers, commands, URLs, or quoted text.

Apply these rules:
- Use one consistent name for each thing.
- Prefer short, common words: use, start, help, make sure, before, after, about, get, and show.
- Remove marketing adjectives, filler, repetition, and vague statements.
- Use active voice when the actor is known.
- Use a verb for an action. For example, write “analyze the log,” not “perform an analysis of the log.”
- Use simple verb forms. Avoid stacked auxiliary verbs and unnecessary “-ing” forms.
- Put one idea or instruction in each sentence.
- Keep instructions to 20 words or fewer and descriptions to 25 words or fewer when practical.
- Do not use contractions or semicolons.
- Keep each paragraph to one topic and no more than six sentences.
- For procedures, use a numbered vertical list with one imperative action per item. Put each condition before its command.
- Use American spelling for English text.

Use every rule strictly for procedures, safety text, runbooks, and error messages. For general prose, keep natural word choice while following the sentence, structure, and active-voice rules.

Before you answer, check for long sentences, semicolons, contractions, passive voice, nominalizations, unnecessary “-ing” forms, and inconsistent names.

Output only the rewritten text. Do not add a preamble, summary, explanation, or closing remark.
